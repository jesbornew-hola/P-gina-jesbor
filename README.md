# Jesbor Barbería · Finanzas

Web para llevar el control financiero diario de la barbería: registra cada corte con un toque, vende productos y ve cuánto generaste.

## Cómo usarla

Abre `index.html` en el navegador (celular o computadora). No necesita instalación ni internet.
También puedes publicarla gratis con **GitHub Pages** (Settings → Pages → rama principal, carpeta raíz).

## Páginas

| Página | Para qué sirve |
| --- | --- |
| **Dashboard** | Ingresos de hoy vs. ayer, meta diaria, cortes y productos del día, ganancia neta, gráfico de los últimos 7 días, resumen automático, métodos de pago y actividad reciente. Botones rápidos para agregar cortes. |
| **Cortes** | Tus servicios con su precio y un botón **Agregar corte** en cada uno. Crear, editar o eliminar servicios, y registrar cortes personalizados (otro precio u otra fecha). |
| **Productos** | Catálogo con botón **Vender**, control de stock (opcional), margen de ganancia, reposición y **Venta suelta** para productos que no están en el catálogo. |
| **Finanzas** | Informe por día, ayer, 7 días, mes o fechas personalizadas: estado de resultados, ingresos por servicio y por producto, métodos de pago y todos los movimientos. Exportar a CSV (Excel) e imprimir. |
| **Gastos** | Registrar gastos (insumos, alquiler, etc.) para calcular la ganancia real, con resumen por categoría. |
| **Ajustes** | Nombre del negocio, moneda, decimales, meta diaria, tema claro/oscuro, copia de seguridad y restauración. |

## Datos

Todo se guarda en el navegador del dispositivo (localStorage). Usa **Ajustes → Descargar copia** con regularidad; con **Restaurar copia** pasas los datos a otro dispositivo.
